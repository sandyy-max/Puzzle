# Banana Brain

CIS046-3 Software For Enterprise — Banana API puzzle game.

## Run

```powershell
cd d:\Level_6\SoE_Assignment\Puzzle
copy .env.example .env
npm install
npm start
```

Open http://localhost:3000

## Step 2 status
